GOOGLE SIGN-IN

Connect Google securely

Data Draft AI needs a Google Web OAuth client ID before anyone can sign in. The client ID is public; do not paste a client secret into this website.

  1. Open Google Cloud Console credentials.
  2. Create or select a project, then create an OAuth client ID for a Web application.
  3. In Authorized JavaScript origins, add http://localhost:3000. Add your HTTPS domain when you publish Data Draft AI.
  4. Copy the client ID to config.js, replacing the blank value, then refresh this page.

Google sign-in must be verified on the server and stored in a database before public production use.
